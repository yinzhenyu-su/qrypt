## ADDED Requirements

### Requirement: 读事件暴露读策略执行结果

每个读事件 SHALL 追加记录本次读的意图（`bulk`、`interactive` 或 `probe`）、实际使用的并行流数，以及预取被取消时的取消原因。汇总事件 MUST 记录本次读的意图与最大并行流数；窗口/阶段明细事件 MUST 记录该窗口实际使用的流数。未声明意图的旧调用方 MUST 记录为空值，不得伪造默认意图。追加 MUST 采用新增字段的方式，不改变既有字段的名称与语义；未携带这些字段的旧事件与旧消费方 MUST 继续可解析。

后台预取取消 MUST 记录为取消结果并携带原因，MUST NOT 计为前台读取失败；前台调用方取消 MUST 继续按现有错误/取消语义记录。

#### Scenario: bulk 事件携带意图与流数

- **WHEN** 一次 `bulk` 读使用多个并行 Range 完成
- **THEN** 其汇总事件给出 `bulk` 意图与最大并行流数，窗口明细事件给出各窗口实际流数

#### Scenario: 交互与探测事件给出单流

- **WHEN** 一次 `interactive` 或 `probe` 读完成
- **THEN** 其读事件给出的并行流数为 1

#### Scenario: 后台预取取消不报告为读取失败

- **WHEN** 后台预取因读缓存失效、会话释放或调用方取消而停止
- **THEN** 对应事件记录取消原因与取消结果，但不计为前台读取失败

#### Scenario: 前台取消保留现有语义

- **WHEN** 前台读本身被调用方取消
- **THEN** 该读事件继续按现有错误/取消语义记录，不因新增字段改变

#### Scenario: 旧事件与旧消费方仍可解析

- **WHEN** 消费方读取不含新增字段的旧事件，或读取包含新增字段的新事件
- **THEN** 既有字段的名称与语义保持不变，新增字段缺失时可忽略
